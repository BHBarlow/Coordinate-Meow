# Coordinate-Meow

## What is Coordinate-Meow?
**Coordinate-Meow** is a multi-host Linux orchestration and automation tool designed for Collegiate Cyber Defense Competition (CCDC) blue teams. It enables defenders to concurrently manage, enumerate, harden, and monitor multiple target machines over SSH from a centralized coordinator.

### Key Capabilities:
- **Concurrent SSH Execution:** Run commands or shell scripts simultaneously across target hosts using credentials, SSH keys, or JSON configs.
- **Automated Hardening:** Rapidly deploy firewall rules, lock down SSH and PAM configurations, rotate passwords, and strip unwanted SUID permissions.
- **System Enumeration:** Collect host inventories, open ports, user accounts, cron jobs, web/database setups, and audit for persistence mechanisms or backdoors.
- **File Transfers & Backups:** Upload defense tooling to target machines and pull critical configs and log files back to the coordinator.
